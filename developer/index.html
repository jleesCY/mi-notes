Development Setup

Prerequisites

  • Android Studio (latest stable)
  • JDK 21
  • Android SDK 37
  • A device or emulator (Android 8.0+)

Installation

git clone https://github.com/mi-app-hub/mi-notes.git
cd mi-notes

Running the App

./gradlew installDebug        # build + install on the connected device
./gradlew testDebugUnitTest    # run the logic tests

Or open the project folder in Android Studio and press Run. The app is a single Gradle module; editor behaviour is tested with Robolectric, so the tests need no device.

Core Concepts

State Management

NotesStore owns notes and folders and saves them as JSON in app-private storage; NotesViewModel holds the stores and app-wide UI state (the open note, sheets, dialogs) and coordinates Undo. Decisions (filtering, sorting, previews, Markdown) are pure, unit-tested functions.

The Note Format

A note's body is plain text plus spans: ranges, each with one type (weight, italic, colour, size, list paragraph, alignment, divider, block…). It changes only by adding: a new span type or a field with a default. An app that meets a type it doesn't know reads it as UNKNOWN and skips it, so backups open in older and newer versions alike. RichCodec turns the format into Android spans for the editor and back; a new kind needs both directions, Markdown, and a round-trip test.

Gesture Logic

The Pills, sheets and note cards share one pan detector that tracks the finger in screen coordinates and always settles on release, animated with Material 3 Expressive springs.

Building

Build a minified release APK with Gradle:

./gradlew assembleRelease
# → app/build/outputs/apk/release/mi-notes-<version>-release.apk

Signing: create a keystore.properties file in the project root (it is git-ignored) with storeFile, storePassword, keyAlias and keyPassword. Without it, the release APK is built unsigned.

Versioning: MAJOR.MINOR.PATCH: major for massive changes, minor for significant new features, patch for fixes and smaller improvements.
